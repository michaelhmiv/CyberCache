# Legendary Effects

Legendary weapons can carry one of **26 named legendary effects** — signature behaviors like second-opinion revives, jackpot payouts, and market-crash salvage multipliers that define endgame builds. Cache-forged weapons never carry a legendary effect; effects come from world and boss drops.

This page will carry the honest full table — every effect, its trigger, and its implementation status (some effects are fully simulated, some run as declared proxies where the underlying system doesn't exist yet, e.g. there is no boss healing for an anti-heal effect to eat). The generated table lands here in Wiki Phase 3, rendered directly from the game's effect definitions so it cannot drift.
