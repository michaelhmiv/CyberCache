# Shield-Tech

Shield-Tech is the service economy for shield behaviors (see [[Combat]]): recalibrating a shield from one behavior to another — say, Standard to Nova — is skilled work done in **calibration points**, burning **Calibration Cores** (consumed worst-first). It runs in two lanes, like repair: post the job to the Shield Tech board inside [[The Market]] for another player to take, or run it yourself as a timed workshop job.

Escrow is full-price up front with pro-rata refunds. One recalibration is **banned outright** at every layer of the system: **Legendary → Standard**. A legendary shield can be moved between the exotic behaviors, but it can never be plain.
