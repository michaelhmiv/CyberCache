# Dashboard HUD Redesign Notes

The dashboard should feel like a badlands looter board, not a clean spaceship cockpit.

Reference direction after reviewing Borderlands 4 gameplay material:

- Keep the numbers-go-up readability, but present it as a rough bounty board / field station.
- Favor dusty orange, red, black, worn metal, thick outlines, crooked signs, hazard-strip accents, and hand-painted labels.
- Keep some high-tech UI hints only where gameplay needs them, but avoid a sterile sci-fi console look.
- Use hard black outlines, angled panels, chunky icon blocks, and imperfect sign-like geometry instead of polished glass panels.
- Anchor the dashboard around the current turf or boss target so it feels like a place the hunter is operating from.
- Make XP, level, loot, cash, scrap, and cache changes visibly pop as short-lived reward events.

The dashboard remains a command surface only. It visualizes existing store state and routes players to Fight, Inventory, Cache, Mastery, Workshop, and Market without duplicating reward-generation logic.
